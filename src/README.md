## 📌 What is this?

The **Cyber Safety Response System** is an interactive web application that presents users with realistic online safety scenarios. Users respond within a **30-second window** per scenario. The platform evaluates their awareness and gives a detailed safety score.

---

## ✨ Features

- 🎯 10 scenario-based questions — 5 MCQ + 5 Written responses
- ⏱️ 30-second animated countdown timer per question
- 🔒 Answers auto-lock on timeout
- 📊 Instant result dashboard with animated score rings
- 📱 Fully responsive — Mobile, Tablet, Desktop
- 🎨 Modern dark cyber-themed UI
